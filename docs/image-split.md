# 이미지를 컷으로 분할

`main` `300e39e` 기준. 한 장에 여러 장면이 들어 있는 이미지를 격자로 나누고, 고른 조각마다 새 컷을 하나씩 만듭니다. 새 의존성은 없습니다.

## 사용

1. **파일 → 이미지를 컷으로 분할**에서 PNG·JPEG·WebP 파일(64 MiB, 각 변 8192px 이하)을 고릅니다.
2. 가로·세로 칸 수(1~6)를 정합니다. 기본은 2×2입니다.
3. 분할선을 끌어 위치를 맞춥니다. 바깥 테두리 선도 끌 수 있어 제목·여백을 잘라낼 수 있습니다. 칸 수를 바꾸면 선은 균등 분할로 돌아갑니다.
4. 미리보기의 조각을 클릭하거나 아래 체크 상자로 컷으로 만들 조각을 고릅니다. 고르지 않은 부분은 흐리게 보입니다.
5. **컷 만들기**를 누르면 고른 조각 수만큼 컷이 현재 컷 바로 뒤에 읽는 순서(왼쪽→오른쪽, 위→아래)로 생기고, 첫 번째 새 컷으로 이동합니다.

새 컷의 구성:

| 레이어 | 내용 |
| --- | --- |
| 다시 그리기 (위, 선택됨) | 빈 레이어. 바로 그릴 수 있습니다 |
| 원본 조각 N (아래) | 잘라낸 조각. 원본 조각 크기와 파일 이름을 레이어 정보로 보관합니다 |

## 동작 규칙

- 프로젝트의 모든 컷은 캔버스 크기가 같습니다. 조각은 비율을 유지해 캔버스 가운데에 맞춥니다. **캔버스에 맞게 확대**를 끄면 캔버스보다 작은 조각은 원래 크기로 둡니다(큰 조각은 항상 축소).
- 기존 컷과 그 Undo 기록은 바뀌지 않습니다. 새 컷은 Undo 기록 없이 시작합니다.
- 컷 추가는 다른 컷 추가·삭제와 마찬가지로 실행 취소 대상이 아닙니다. 필요 없으면 컷 삭제를 사용합니다.
- 컷은 최대 30개입니다. 한도를 넘으면 하나도 만들지 않고 안내합니다. 도중에 실패해도 만들던 컷을 모두 되돌립니다.
- 조각을 하나 만들 때마다 압축해 두므로 여러 조각을 만들어도 전체 크기 캔버스는 한 번에 하나만 메모리에 올립니다.
- 원본 이미지는 프로젝트에 따로 저장하지 않습니다. 저장되는 것은 각 컷의 조각 레이어입니다.

## 한계

- 분할은 직선 격자입니다. 칸마다 크기가 다른 자유 배치나 자동 컷 경계 인식은 없습니다.
- 조각마다 따로 위치를 맞추는 기능은 없습니다. 가져온 뒤 원본 조각 레이어를 자유 변형(Ctrl+T)으로 조정할 수 있습니다.
