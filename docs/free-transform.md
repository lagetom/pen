# 이미지·레이어 자유 변형

기준: `main` `7b72edf5`, 작업 브랜치: `feat/free-transform`. 기존 Canvas 2D 엔진·브러시·타일 히스토리를 유지하고 변형 트랜잭션을 별도 모듈로 추가했습니다. 외부 의존성 추가는 없습니다.

## 사용

- **Ctrl+T** 또는 **자유 변형**: 활성 레이어의 불투명 픽셀 경계, 선택이 있으면 해당 사각 영역을 대상으로 시작합니다.
- 네 모서리 핸들을 드래그하면 반대 모서리를 고정하고 크기를 조절합니다. **비율 고정**은 기본 켜짐이며 해제할 수 있습니다. 회전한 상태에서도 로컬 축을 기준으로 크기를 조절합니다.
- 위쪽 원형 핸들로 회전하고 테두리 내부를 드래그해 이동합니다. 너비·높이는 **px / %**, 각도는 도 단위로 직접 입력할 수 있습니다. `%`의 100은 화면에 표시된 **기준** 소스 크기입니다.
- **Enter / 확정**으로 완료, **Escape / 취소**로 시작 전 픽셀과 선택을 복원합니다. 창 포커스를 잃으면 안전하게 취소합니다. 포인터 취소·캡처 상실은 현재 드래그 전 변형 수치로 돌아가며 변형 세션은 유지합니다.
- Ctrl+휠, 확대 버튼, Ctrl++/−/0, M 보기 반전은 변형 중에도 사용할 수 있습니다. 핸들·선택·가이드는 원본 캔버스 좌표 변환을 공유합니다.
- 변형 중 레이어/컷 편집·프로젝트 열기/저장·내보내기를 잠그고 자동 저장을 미룹니다. 미확정 미리보기를 프로젝트 데이터로 저장하지 않습니다. 확정 또는 취소 후 기존 V·S·브러시·저장 기능을 계속 사용할 수 있습니다.

숫자 입력 중 B/E/H/S 등의 도구 단축키는 실행하지 않으며 IME 조합 중 Enter/Escape도 가로채지 않습니다. 유효하지 않은 수치는 적용하거나 확정하지 않습니다. 크기 범위는 1–32768px, 각도는 −36000–36000°입니다. 출력 캔버스 크기와 기존 픽셀/히스토리 한도는 바꾸지 않습니다. 캔버스 밖 결과는 확정 시 잘리며 Undo로 복원합니다.

## 가져온 이미지와 원본

PNG를 가져오면 기존처럼 현재 캔버스에 맞춰 초기 배치하고 즉시 자유 변형을 시작합니다. 이 **최초 변형 세션**은 축소된 레이어가 아니라 디코딩된 원본 이미지를 소스로 사용합니다. 자동으로 50%가 된 이미지를 100%로 되돌릴 때 원본 픽셀로 다시 그립니다. 모든 미리보기는 동일한 소스에서 계산하여 이전 미리보기를 다시 확대/회전하는 누적 재샘플링을 피합니다.

이미지 가져오기 자체와 후속 자유 변형은 별도 작업입니다. 최초 변형을 취소하면 가져온 레이어의 초기 배치를 정확히 복원합니다. 가져오기까지 취소하려면 Ctrl+Z를 사용합니다. 크기를 바꾸지 않고 확정하면 불필요한 변형 히스토리를 만들지 않습니다.

확정 이후에는 래스터 레이어로 편집하며, 다음 Ctrl+T는 현재 픽셀을 새 소스로 사용합니다. 원본 파일의 전체 픽셀을 프로젝트에 중복 저장하는 스마트 객체 기능은 추가하지 않았습니다. 새 변형 세션이나 재접속 이후에도 원본 해상도의 모든 세부 정보를 복원한다고 보장하지 않습니다.

원본의 **크기·파일 이름 정보**는 선택적인 `layers[].imageSource: { width, height, name }` 메타데이터로 보존합니다. `.mpaint` v1/v2의 PNG 필드와 버전을 변경하지 않습니다. 정보가 없는 이전 프로젝트도 열 수 있으며, 이전 앱은 추가 필드를 무시하고 확정된 픽셀을 읽을 수 있습니다. 가져온 파일 이름은 최대 100자, 원본 크기는 기존 가져오기 한도인 각 변 8192px 이내로 검증합니다. 메타데이터는 원본 파일을 포함하지 않으며 현재 레이어 크기와 다를 수 있습니다.

## 데이터·메모리

`src/free-transform.ts`가 시작 전 ImageData, 선택 밖 배경, 불변 소스 및 변형 수치를 보유합니다. 포인터 이동은 수치만 바꾸고 미리보기는 기존 프레임 예약을 통해 그립니다. 브러시 입력 경로에서 변형 버퍼를 생성하거나 불투명 경계를 검색하지 않습니다.

확정 시 이전·이후 ImageData를 하나의 기존 Undo 명령으로 기록합니다. 다른 레이어와 컷은 바꾸지 않습니다. 미리보기·원본 버퍼는 완료/취소 후 해제하며 히스토리는 기존 50단계/128 MiB 정책을 따릅니다. 전체 레이어 변형의 최악 히스토리 용량을 할당 전에 확인합니다. 임시 Canvas, 디코딩된 원본 이미지와 브라우저 캐시 메모리는 히스토리 용량과 별도입니다.

## 변경 파일

| 파일 | 변경 |
| --- | --- |
| `src/free-transform.ts` | 소스 스냅샷, 경계 검색, 회전/비율/핸들 좌표, 미리보기·확정·취소 |
| `src/main.ts`, `src/style.css` | 변형 UI·단축키·입력·작업 잠금, 가져오기 직후 연결 |
| `src/engine.ts` | 선택 원본 메타데이터 검증·저장·복원 |
| `src/storyboard.ts`, `src/layer-edits.ts` | 비활성 컷 직렬화·레이어 복제 시 원본 정보 보존 |
| `tests/free-transform.spec.ts` | 자유 변형 핵심 정확성 검사 8개 |
| `tests/paint.spec.ts`, `tests/selection-panel.spec.ts` | 기존 PNG 가져오기 검증에서 새 최초 변형을 명시적으로 확정 |

기존 테스트의 픽셀 기대값이나 반복 부하는 줄이지 않았습니다. 원래의 점/작은 원 25회, Undo/Redo 8회, 레이어 5개 정책을 유지합니다.

## 검증

개발 중 변형 검사, 실패한 단위 전환 동기화와 숫자 소수 입력 수정 관련 검사, 기존 편집·PNG 경로 검사 4개를 실행했습니다.

- 최종 `npm run build`: TypeScript 검사·Vite 빌드·서비스 워커 생성 성공. 앱 번들 94.83 kB(gzip 31.60 kB), 기존 PSD Worker는 별도 지연 로딩을 유지합니다.
- 최종 `npm test -- --reporter=line`: 기존 58개 + 새 8개 = **66개 모두 통과**, 약 **1.7분**, 자동 재시도 없음. 전체 회귀는 한 번 실행했습니다.
- 변형 수치·실시간 미리보기·비율/단위·회전·이동·네 모서리 고정점, 확대/반전 핸들, 취소/Undo/Redo, 선택 외부 픽셀, 입력 보호·소수/잘못된 입력·작업 잠금, 원본 1px 줄무늬의 축소→원본 재확대 검사 통과.
- 프로젝트 재열기·IndexedDB 새로고침 복구·PSD 전체 레이어 RGBA/재합성, 레이어/컷 격리, 비활성 컷 메타데이터, v1/v2·메타데이터 없는 이전 파일·잘못된 정보 거부 검사 통과. 기존 V·S·M·I·연필/가이드·프리셋·PSD·오프라인 검사도 유지합니다.
- 반복 브러시 표본: 히스토리 7.375 MiB, 최대 렌더 작업 약 2.00ms, 평균 이벤트 처리→렌더 약 0.91ms. 기존 브러시 계산 코드는 변경하지 않았습니다. Linux Chromium 자동화 표본이며 표시 장치·하드웨어 지연 또는 환경 간 성능 동등성을 보장하는 수치는 아닙니다.
- 확대/반전/회전 중 작업 화면 스크린샷을 확인했습니다.

PSD는 변형한 레이어의 전체 RGBA와 레이어 재합성이 원본 Canvas와 정확히 일치하는지 검사합니다. `ag-psd`의 별도 8비트 합성 미리보기는 반투명 픽셀에 흰색 매트를 인코딩/제거하며 양자화가 생깁니다. 새 검사는 알파의 정확한 일치 및 전경색×알파 오차 1.5/255 이내를 확인합니다(인코더 정수 절삭 <1 + 디코더 반올림 ≤0.5). 레이어 픽셀 정확성 검사를 허용 오차로 대체하지 않았으며 기존 PSD 검사도 유지했습니다.

Windows 실제 타블렛·운영체제 클립보드/파일 선택 권한 및 Photoshop에서 새로 수동 검증한 결과는 아닙니다. 실제 표시 지연이나 FPS를 보장하지 않습니다.
