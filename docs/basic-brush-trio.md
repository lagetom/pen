# 기본 브러시 3종

기준: 최신 `main` `81fcc2a`, 작업 브랜치: `feat/basic-brush-trio`. 기존 펜·연필·지우개 입력과 타일 히스토리를 유지하면서 거친 잉크펜·싸인펜·볼펜을 추가했습니다. 외부 의존성은 추가하지 않았습니다.

## 사용

왼쪽 도구 모음 또는 브러시 선택 메뉴에서 선택합니다.

| 브러시 | 기본 크기 | 기본 불투명도 | 고유 설정 기본값 |
| --- | --- | --- | --- |
| 거친 잉크펜 (Rough Ink) | 8px | 100% | 외곽 거칠기 35% |
| 싸인펜 (Felt Tip) | 12px | 100% | 가장자리 부드러움 35% |
| 볼펜 (Ballpoint) | 3px | 90% | 농도 변화 20% |

크기·불투명도·고유 설정은 브러시마다 독립적입니다. 슬라이더/숫자 입력과 기존 `[`/`]`는 현재 브러시에만 적용합니다. 색상은 기존 전경색을 공유합니다. 환경 설정 표에서도 7종의 크기·불투명도와 새 3종의 질감을 확인/수정할 수 있습니다. 변경은 그림 히스토리를 소비하지 않으며 로컬 설정으로 저장합니다. 진행 중인 획은 시작할 때 캡처한 값을 사용합니다.

## 표현과 렌더링

- **거친 잉크펜**: 중심부를 불투명하게 유지하고 좁은 외곽에 고정 시드의 약한 반경 불규칙성을 적용합니다. 같은 팁을 거리 기준으로 배치하므로 작은 원과 짧은 획이 끊어지지 않습니다.
- **싸인펜**: 기존 펜의 원형 점·둥근 선 끝/연결 경로를 사용합니다. 좁은 반투명 외곽과 진한 내부 경로로 부드러운 가장자리를 만듭니다. 한 획의 브러시 불투명도는 기존 원본/마스크 합성으로 제한하여 겹쳐 그리는 동작이 설정 불투명도를 넘지 않게 합니다.
- **볼펜**: 얇은 팁에 낮은 강도의 고정 시드 농도 차이와 거리 스탬프 순번에 따른 미세한 변화를 적용합니다. 촘촘한 간격으로 배치해 점선화를 피합니다. 기본 브러시 불투명도는 90%입니다.

프레임별 난수 생성·필터·외부 텍스처를 사용하지 않습니다. 거친 잉크펜/볼펜의 거리 위상은 포인터 이벤트 분할, 중복 좌표와 프레임 렌더에 의존하지 않습니다. 싸인펜은 기존 경로 방식이며 같은 입력 좌표열의 결과가 프레임 빈도와 무관하게 재현됩니다.

## 캐시와 자원

팁은 브러시 종류·크기·색상·질감 조합을 처음 사용할 때 한 번 생성해 재사용합니다. 팁 해상도는 크기에 따라 16–192px입니다. 정규화한 외곽 비율과 제한된 노이즈로 크기 변경 시에도 과한 불규칙성을 피합니다. 일반 펜과 기존 연필은 새 팁 생성/캐시 조회를 거치지 않습니다. 싸인펜은 경로 렌더링이므로 별도 팁 버퍼가 필요하지 않습니다.

팁 캐시는 최대 24개/2 MiB로 제한하며 오래 사용하지 않은 항목부터 해제합니다. 사용 중인 팁은 참조 수로 보호하고 획 종료/취소 때 반환합니다. 활성 참조가 남아 있으면 해당 팁을 중간에 제거하지 않습니다. 이 한도는 유지하는 팁의 한도이며 기존 프로젝트 Canvas·획 마스크·히스토리 메모리는 별도입니다.

화면 밖 구간의 스탬프 반복은 건너뛰고 거리 위상/순번만 진행합니다. 비활성 브러시나 닫힌 시험 패널에는 렌더 타이머를 두지 않습니다. 원본/마스크 버퍼, 실행 중 팁 참조, 시험 패널 Canvas는 완료/취소/닫기 때 해제합니다.

## 브러시 테스트 화면

상단 **브러시 테스트**에서 세 브러시의 독립된 시험 영역을 엽니다. 현재 설정과 전경색으로 작은 원·짧은 직선·긴 곡선·지그재그 샘플을 생성하며 직접 그리거나 지우고 다시 샘플을 만들 수 있습니다. 설정은 패널을 열 때 복사합니다. 새 설정으로 시험하려면 닫고 다시 엽니다.

각 영역은 별도 `Paint`를 사용하며 프로젝트 엔진을 전달받지 않습니다. 프로젝트 픽셀·레이어·컷·리비전·Undo 기록은 바꾸지 않습니다. 닫을 때 포인터/스트로크·예약 프레임·시험 Canvas·히스토리 버퍼를 정리합니다.

## 설정·프리셋·파일 호환성

- 기존 로컬 도구 설정과 v1/v2 도구 세트에 새 브러시 키가 없으면 위 기본값을 보충합니다. 기존 네 도구 값은 유지합니다. 잘못된 새 크기·불투명도·질감 값은 검증합니다.
- 단일 브러시와 도구 세트 모두 새 종류를 저장/적용합니다. 새 고유 설정은 `{version:1, amount:0..100}`이며 각 브러시의 위 설정 항목에 대응합니다.
- 프리셋 JSON은 **version 3**으로 내보내고 **version 1/2/3**을 읽습니다. 로컬 저장은 `mini-paint.user-presets.v3`, 이전 v2/v1 키는 읽기 경로로 보존합니다. v2에서 삭제한 예시 프리셋을 마이그레이션으로 다시 생성하지 않습니다. 이전 앱이 v3 파일을 읽을 수 있다고 표시하지 않습니다.
- `.mpaint` v1/v2 구조는 변경하지 않습니다. 브러시 결과는 기존 레이어 PNG 픽셀로 저장하며 PNG·PSD·자동 저장·복구 경로를 유지합니다. 한 스트로크는 하나의 기존 타일 Undo 명령입니다.

커스텀 브러시 편집기, 외부 브러시 파일 가져오기, 마켓 기능은 이번 범위에 포함하지 않습니다.

## 검증

개발 중 브러시별 실제 점 25회·작은 원 25회·곡선/지그재그·8회 Undo/Redo 검사 3개와 새 기능 정확성 검사 6개가 통과했습니다. 기존 도구 설정/프리셋 관련 검사 4개, 변경된 저장/키 구분 및 캐시 키 관련 검사도 우선 실행했습니다.

입력 분할·프레임·캐시 재생성에 따른 질감 재현성, 1px 점, 취소, 화면 밖 구간, 잉크 중심부·볼펜 선 폭·싸인펜 부드러운 가장자리/불투명도, 7종 독립 값·질감·새로고침, v1/v2 읽기와 v3 저장, 캐시 키/상한/활성 참조·해제, 시험 패널의 프로젝트 불변, 레이어 격리·PNG/PSD 레이어 RGBA·프로젝트 재열기·자동 복구를 검사합니다. 반복 부하는 기존 25% 수준을 유지합니다.

- 최종 `npm run build`: TypeScript 검사·Vite 빌드·서비스 워커 생성 성공. 초기 앱 118.57 kB(gzip 39.08 kB), 기존 PSD Worker는 별도 지연 로딩을 유지합니다.
- 최종 `npm test -- --reporter=line`: 기존 75개 + 새 9개 = **84개 모두 통과**, 약 **2.5분**, 자동 재시도 없음. 최종 빌드/전체 회귀는 각각 한 번 실행했습니다.
- 기존 펜·연필·지우개·페인트통·자유 변형·선택/레이어/컷·프리셋·PSD·파일 호환성·자동 복구·오프라인 검사를 유지했습니다.
- 시험 패널의 샘플/직접 입력·지우기·자원 정리와 작업 화면 스크린샷을 확인했습니다.

최종 Linux Chromium 소프트웨어 환경에서 반복 입력 중 앱이 수집한 표본입니다. 새 스탬프 브러시의 기본 설정에서는 동일 팁을 한 번만 생성해 1 KiB씩 재사용했고, 획 종료 후 활성 참조는 0이었습니다.

| 브러시 | 최대 렌더 작업 | 앱 입력 계측→렌더 평균 | 히스토리 |
| --- | --- | --- | --- |
| 기존 펜 | 약 2.30ms | 약 0.85ms | 7.375 MiB |
| 거친 잉크펜 | 약 2.50ms | 약 0.85ms | 9.25 MiB |
| 싸인펜 | 약 2.50ms | 약 0.91ms | 9.25 MiB |
| 볼펜 | 약 2.80ms | 약 0.98ms | 7.00 MiB |

기존 계측 시작점에서 렌더 작업 완료까지의 표본이며 최초 원본 캡처·이벤트 대기·물리적 입력부터 실제 표시까지의 전체 지연을 측정한 값은 아닙니다. 환경별 성능 동등성이나 FPS 보장값으로 사용하지 않습니다. 실제 Windows·타블렛·표시 지연·Photoshop 수동 검증은 별도입니다.
