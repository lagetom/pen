# 원본 크기 가져오기 · 캔버스를 이미지 크기로

`main` `866c2d3` 기준. 새 의존성과 파일 형식 변경은 없습니다.

## 원본 크기로 가져오기

붙여넣기(Ctrl+V)와 **파일 → PNG 이미지 가져오기**는 이미지를 항상 **원본 크기(1:1)** 로 캔버스 가운데에 놓고 자유 변형 상태로 들어갑니다. 이전에는 캔버스보다 큰 이미지를 자동으로 축소했습니다.

- 캔버스보다 큰 이미지는 넘친 채로 놓입니다. 변형 중에는 원본 전체를 기준으로 다시 그리므로, 줄이거나 옮기면 가려져 있던 부분이 나타납니다.
- **확정하면 캔버스를 벗어난 부분은 잘립니다.** 가져올 때 안내 문구로 알립니다.
- 크기를 줄이려면 모서리 손잡이를 끌거나 너비·높이를 입력합니다(단위를 %로 바꾸면 원본 대비 비율).

## 캔버스를 이미지 크기로

가져온 직후의 변형 막대에 **캔버스를 이미지 크기로** 버튼이 나옵니다(이미지와 캔버스 크기가 같으면 숨김). 누르면 확인 후:

- 캔버스가 이미지의 원본 크기가 되고, 이미지는 손대지 않은 원본 픽셀로 캔버스를 꽉 채웁니다.
- **모든 컷의 크기가 함께 바뀝니다.** 이 프로젝트 형식은 컷마다 다른 캔버스 크기를 지원하지 않습니다.
- 기존 그림은 가운데 기준으로 유지되고, 새 크기를 벗어나는 부분은 잘립니다.
- **실행 취소 기록이 지워지며 이 작업은 되돌릴 수 없습니다.** 필요하면 먼저 프로젝트를 저장하세요.
- 각 변 4096px를 넘는 이미지, 또는 컷당 레이어 픽셀 합계 128백만을 넘게 되는 경우에는 바꾸지 않고 안내합니다.

컷은 한 번에 하나씩 풀고 크기를 바꾼 뒤 다시 압축하므로 컷 수와 무관하게 메모리 사용이 제한됩니다.
