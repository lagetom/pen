# 선택 영역·레이어 패널

기준은 `main`의 `4f76d04b38d4e67dfc5793a9d66b6d7c4e716bce`이며 작업 브랜치는 `feat/selection-layer-panel`입니다. 기존 작업 브랜치를 덮어쓰지 않으며 main 병합은 별도 요청을 기다립니다.

## 사용

- **S**: 현재 활성 레이어의 사각 선택 도구. 드래그로 정수 픽셀 경계를 지정하고 내부 드래그로 선택 픽셀을 이동합니다. 투명도와 선택 밖 픽셀을 보존하며, 완료한 이동 전체가 Undo 명령 하나입니다.
- **Ctrl+A / Ctrl+D**: 전체 선택 / 선택 해제. 선택 자체는 히스토리를 소비하지 않습니다.
- **Ctrl+C / Ctrl+X / Ctrl+V**: 선택 복사 / 잘라내기 / 새 레이어 붙여넣기. 앱 내부 버퍼로 투명 픽셀을 그대로 복사하며, 붙여넣기는 활성 레이어 바로 위에 독립 레이어를 만듭니다. 앱 버퍼가 있을 때 Ctrl+V는 이를 우선 사용합니다.
- 시스템 클립보드 PNG 쓰기를 지원하면 함께 복사합니다. 권한이 거부되어도 내부 복사는 유지하고 안내합니다. 외부 PNG의 브라우저 붙여넣기 이벤트는 기존 PNG 가져오기 경로로 처리합니다. 운영체제 권한과 실제 클립보드 UI는 브라우저 정책에 따릅니다.
- **Delete**: 선택이 있으면 해당 영역만 지우며, 없으면 기존처럼 활성 레이어 내용을 지웁니다. 삭제·잘라내기·붙여넣기 모두 Undo/Redo를 지원합니다.
- **Escape**, 포인터 취소·캡처 상실·창 포커스 상실: 진행 중인 이동/선택을 취소하고 원본 픽셀·이전 선택을 복원합니다.
- **V**: 기존 활성 레이어 전체 이동. **H**: 화면 이동. 별도 **전체 그림 이동** 도구는 현재 컷의 모든 대상 레이어에 같은 정수 이동량을 적용합니다. 숨긴 레이어 포함 옵션은 기본 켜짐이며, 이동 전체가 Undo 명령 하나입니다.
- 확대·보기 반전은 기존 캔버스 좌표 변환을 재사용합니다. 선택 테두리는 점선 DOM 오버레이이며 포인터를 가로채지 않고 PNG/PSD/프로젝트 픽셀에 들어가지 않습니다.
- 레이어 변경·Undo/Redo·컷/프로젝트 전환 시 선택을 해제합니다. 드래그 중 컷 전환과 구조 편집은 차단하며, 이동을 완료하거나 취소한 뒤 전환할 수 있습니다.

이동 확정 시 캔버스 밖 픽셀은 잘리며 Undo로 복원할 수 있습니다. 선택은 이동·복사·삭제를 위한 영역이며 브러시를 제한하는 마스크는 이번 범위에 포함하지 않습니다. 올가미·다중 레이어 선택은 구현하지 않습니다.

## 패널

기본 너비 340px, 조절 범위 280–520px입니다. 경계 드래그 또는 경계에 포커스를 둔 상태의 좌우 방향키로 조절하고 상단 버튼으로 접습니다. 취소된 크기 조절은 원래 너비로 복원합니다.

레이어 목록을 위에 배치하고 독립 스크롤, 기본 48px/간결 36px 행, 활성 행 자동 스크롤, 행 드래그 순서 변경을 제공합니다. 순서 변경은 Undo/Redo가 가능합니다. 브러시·색상과 작업 화면·종이 가이드는 접을 수 있습니다. 너비·접기·밀도·설정 섹션 상태는 브라우저 로컬 설정이며 프로젝트 픽셀과 분리합니다.

`LayerList`는 행 DOM과 레이어별 썸네일을 재사용합니다. `Paint.changed`가 변경 레이어를 전달하며, 드로잉 중에는 썸네일 생성을 미루고 획 완료 후 해당 레이어만 갱신합니다. 기존 브러시 계산·타일 합성·연필 질감 코드는 변경하지 않습니다.

## 변경 파일

| 파일 | 역할 |
| --- | --- |
| `src/selection.ts` | 사각 좌표, 선택 삭제, 선택/전체 그림 이동 트랜잭션, 클립보드 |
| `src/layer-panel.ts` | 행/썸네일 캐시, 드래그 순서, 크기 조절·설정 보관 |
| `src/engine.ts` | 변경 레이어를 기존 changed 콜백에 전달 |
| `src/main.ts` | 도구·선택 표시·입력·단축키·기존 저장 경로 연결 |
| `src/style.css` | 패널·행 밀도·점선 오버레이 |
| `tests/selection-panel.spec.ts` | 새 기능 핵심 정확성 9개 검사 |

외부 의존성과 `.mpaint` v1/v2 포맷 변경은 없습니다. 선택과 내부 클립보드는 세션 상태이며 저장하지 않습니다. 실제 픽셀 편집 결과는 기존 프로젝트 저장·자동 복구·PSD에 그대로 반영합니다.

선택/전체 그림 이동은 작업 중에만 원본 Canvas를 보유합니다. 확정 후에는 변경 영역의 이전·이후 ImageData를 히스토리에 남기고 임시 Canvas를 해제합니다. 단일 이동 명령이 기존 128 MiB 히스토리 한도를 초과할 수 있으면 편집 전에 거부하고 안내합니다. 이는 브라우저 전체 메모리 한도가 아니며, 원본·미리보기·히스토리·인코딩 임시 메모리는 별도입니다.

## 검증

- 개발 중 기존 편집 도구 관련 7개 검사 통과. 새 기능 관련 검사와 수정된 클립보드·입력·썸네일 검사를 중심으로 실행했습니다.
- 최종 `npm run build`: TypeScript, Vite 정적 빌드 및 서비스 워커 생성 통과.
- 최종 `npm test -- --reporter=line`: 기존 49개 + 새 9개 = **58개 모두 통과**, 약 **1.4분**. 최종 전체 회귀는 한 번 실행했으며 기록된 최종 소스는 이후 바뀌지 않았습니다.
- 새 검사: 선택 내부만 이동, 투명 픽셀/외부 픽셀 보존, 미리보기와 단일 Undo/Redo, Escape/pointercancel/캡처 상실/blur 취소, 선택 취소, 삭제/복사/잘라내기/붙여넣기, 레이어·컷 격리, 확대/반전 좌표, 전체 선택/해제, 입력창 보호.
- 패널 기본값·상하한·취소·접기·브라우저 복원·행 높이·드래그 순서/Undo·활성 행 스크롤 검사 통과. 드로잉 중 썸네일 drawImage 0회, 완료 후 변경 레이어 1회이며 행 DOM이 재사용됨을 검사했습니다.
- 전체 그림 이동: 숨김 포함/제외, 투명도, 한 명령 Undo/Redo, 취소와 다른 컷 격리 검사 통과.
- 선택 편집 프로젝트 재열기·IndexedDB 새로고침 복구·PNG 오버레이 제외·화면 밖 이동 Undo·메모리 초과 거부·시스템 클립보드 거부 후 내부 복사·외부 PNG/입력 보호 검사 통과.
- 기존 원본 JSON 및 `.mpaint` v1/v2, 파일 저장 오류, 용량 오류, PSD 레이어/합성, 연필/가이드/다중 컷 및 오프라인 회귀를 유지했습니다. 점/작은 원 25회, Undo/Redo 8회, 레이어 5개 등 기존 축소 부하는 늘리지 않았습니다.

Linux Chromium 소프트웨어 환경의 반복 드로잉 표본: 히스토리 7.375 MiB, 최대 렌더 작업 약 2.70ms, 평균 이벤트 처리→렌더 약 0.95ms. 이는 화면 표시나 하드웨어 지연·FPS 보장값이 아니며 환경과 스케줄링 차이가 있어 이전 계측과의 성능 동등성을 단정하지 않습니다. 1440×1000 및 760×800 화면도 확인했습니다. Windows 실제 타블렛·운영체제 클립보드 권한 UI는 별도 수동 검증이 필요합니다.
