# 연필 브러시와 종이 가이드

기준은 `feat/mini-paint-v1` (`3b1ac294`)이며 구현 브랜치는 `feat/pencil-paper-guides`입니다.

## 사용

상단 브러시 선택 또는 왼쪽 도구에서 기본 펜·기본 연필·진한 연필·지우개를 선택합니다. 크기 1–100px, 색상, 불투명도는 공통입니다. 기존 B/E/H 및 Undo/Redo 단축키를 유지합니다. 필압은 모든 기본 드로잉 도구에서 적용하지 않습니다.

우측 작업 화면의 종이 가이드에서 없음·격자·줄노트·점을 선택합니다. 간격 8–64px(초기 24px), 연한 파랑/회색, 진하기 10–80%(초기 30%), 표시 여부를 조절할 수 있습니다. 새 작업 및 가이드 정보가 없는 기존 파일은 ‘없음’으로 시작합니다.

## 최소 변경 구조

`src/pencil.ts`는 고정 시드 xorshift로 96×96px 흑연 팁을 생성합니다. 기본·진한 연필은 서로 다른 시드·입자 분포·알파를 사용합니다. 원형 경계의 작은 요철과 픽셀별 농도로 질감을 만들고, 같은 위치를 다시 지나면 알파가 누적됩니다.

색상·종류별 팁을 최대 12개 캐시합니다. 렌더 프레임마다 난수를 생성하거나 필터를 계산하지 않습니다. 스탬프 간격은 `max(0.5, 브러시 크기 × 0.22)`px입니다. 입력 이벤트가 나뉘거나 프레임 중간에 flush되어도 이동 거리의 위상을 보존합니다. 캔버스 밖의 스탬프 반복은 잘라내되 전체 이동 거리 위상은 유지합니다. 좌표는 1/256px로 양자화하고, 1px 팁은 픽셀 격자에 맞춰 짧은 점이 투명한 가장자리 샘플링 때문에 사라지지 않도록 합니다.

`Paint.begin`의 마지막 선택 인자로 연필 종류를 전달합니다. 기존 6개 인자 호출은 원형 펜/지우개 그대로 동작합니다. Pointer Events, 캡처, coalesced 입력, 좌표 변환 및 타일 기록은 공통입니다. 펜의 경로 렌더링은 유지하며 연필일 때만 별도 마스크 렌더러를 호출합니다. 스트로크의 전체 해상도 원본/마스크 버퍼는 종료·취소 시 해제하고, 히스토리는 레이어 참조와 변경 타일 픽셀만 보존합니다.

재현성은 같은 브라우저 렌더러·설정·좌표 경로를 기준으로 합니다. 브라우저나 그래픽 백엔드가 다르면 Canvas의 미세한 래스터 결과 차이가 있을 수 있습니다. 프로젝트 파일에는 결과 PNG 픽셀을 보존하므로 다시 열 때 브러시를 재생성하거나 스트로크를 다시 그리지 않습니다.

## 가이드의 분리와 파일 호환성

`src/guides.ts`는 가이드 메타데이터 검증과 CSS 오버레이 렌더링을 담당합니다. `#guideOverlay`는 `#paper` 안에서 절대 배치되며 `pointer-events: none`입니다. 종이와 같은 변환을 받아 가이드 간격이 캔버스 좌표에 맞춰 확대·이동됩니다. 별도 전체 해상도 Canvas나 이미지 레이어를 할당하지 않습니다.

오버레이는 래스터 Canvas를 변경하지 않습니다. `Paint.composite`와 PNG 내보내기는 레이어만 사용합니다. 가이드 설정은 편집된 프로젝트 메타데이터로 표시하고 자동 저장하지만, `History.push`를 호출하거나 Redo 분기를 제거하지 않습니다. Ctrl+Z/Y로 그림을 되돌려도 현재 가이드는 유지합니다.

단일 컷 엔진의 version 1에는 선택 필드 `guide`를 추가합니다. 다중 컷 통합 후 앱의 새 저장 파일은 version 2이며 각 `cuts[].guide`에 같은 설정을 저장합니다. 컷 복제 시에는 설정도 복제하고 새 빈 컷은 기본 ‘없음’으로 시작합니다. 아래는 계속 읽을 수 있는 version 1 형식 예시입니다.

```json
{
  "format": "mini-paint",
  "version": 1,
  "width": 1600,
  "height": 1200,
  "name": "연필 스케치",
  "guide": {
    "type": "grid",
    "visible": true,
    "spacing": 24,
    "color": "blue",
    "opacity": 0.3
  },
  "layers": []
}
```

위 예시의 레이어는 포맷 설명을 위해 생략했습니다. 실제 파일은 최소 1개 레이어를 포함해야 합니다. `guide`가 없는 v1 파일·기존 v2 컷·제공된 원본 HTML JSON은 기본 ‘없음’으로 읽습니다. 잘못된 가이드 값은 파일 전체를 거부하고 현재 작업을 유지합니다. 가이드 메타데이터는 파일 저장과 IndexedDB 복구에 모두 포함됩니다. 예전 v1 앱은 v1 파일의 추가 가이드 필드를 무시하고 이미지 픽셀을 읽을 수 있습니다. 다중 컷 version 2 파일은 v2 지원 앱이 필요합니다.

## 검증과 한계

기존 브러시 회귀 테스트를 유지하며 새 테스트는 연필 실제 포인터 점/작은 원 각 100회, 기본/진한 농도 차이·중첩, 분할 입력·flush 횟수와 무관한 픽셀 재현, Undo/Redo·파일 라운드트립·취소, 1px 정수/소수점 탭을 확인합니다.

가이드는 픽셀·레이어·Undo/Redo 분기 불변, 실제 화면 캡처의 격자 선 좌표(100%·400%), 화면 이동 정렬, 입력 통과, 실제 투명/흰 배경 PNG 다운로드의 모든 픽셀 비교, 프로젝트 재열기·자동 복구·기존 파일 기본값을 검사합니다.

진단값은 이벤트 처리→Canvas 렌더 완료의 소프트웨어 작업 계측입니다. 하드웨어 입력 지연이나 FPS 보장값이 아닙니다. 실제 Windows·타블렛 및 긴 작업 세션 검증은 별도입니다.
